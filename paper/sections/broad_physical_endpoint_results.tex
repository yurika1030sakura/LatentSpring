\subsection{Learning from physically corrected references}\label{app:broad-physical-targets}
We compare fine-tuning on original and physically corrected OMol25 references to isolate the contribution of corrected labels at a fixed additional training budget.

\paragraph{Reference pairs.}
Fixed metadata hashes select 128 compositions from the existing 3,000-row block, with 32 each in the 8--16, 17--24, 25--32, and 33--40 atom ranges. Each contributes one reference. A bounded Cartesian L-BFGS search under inversion-averaged eSEN moves all coordinates while preserving geometric validity and the inferred labeled graph. The budget is 96 steps and 160 energy/force evaluations, with a 0.05\,\AA\ per-atom step cap and stopping threshold of 0.1 eV/\AA\ for the maximum atomic force.

We retain the last accepted point when a search stalls or exhausts its budget, keeping all 128 compositions in both sets. Of these searches, 110 meet the force threshold and 124 reduce force RMS. Preparation uses 6,576 eSEN evaluations including inversion pairs. Independent GFN2 calculations score all 256 original and corrected references.

\paragraph{Adaptation and evaluation.}
Two runs start from the same 5.90-million-parameter harmonic checkpoint. Within each run, original- and corrected-reference students share reference indices, source draws, rotation and matching randomness, optimizer settings, and 0.005\,\AA\ centered endpoint smoothing. Each receives 2,000 batch-size-one updates with uniform composition frequency. Training is direct FM regression to the selected empirical reference distribution, without parameter subtraction.

The confirmation panel contains 16 previously ungenerated compositions, eight per size range, absent from both processed corpora and earlier panels. Each model generates 16 draws per composition and run using 128 backbone calls and zero terminal noise; the original parent is regenerated under the same settings. Checkpoints are fixed before evaluation, and outputs remain unoptimized.

Corrected-reference training exceeds matched original-reference training by 5.66 joint-yield points (composition 95\% interval $[2.54,8.59]$), with gains of $+8.20$ and $+3.13$. Relative to the unadapted parent, the difference is $+1.37$ points ($[-3.52,6.05]$), with changes of $-1.95$ and $+4.69$. Corrected labels therefore improve this fine-tuning procedure, while a net advantage over the parent remains unresolved. Intervals condition on the two fits. Beyond label preparation and 256 GFN2 reference checks, the study adds 8,000 updates, 1,536 raw outputs, and 1,536 GFN2 readouts.
