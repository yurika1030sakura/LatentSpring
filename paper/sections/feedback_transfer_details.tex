\subsection{Geometry feedback and physical transfer on the EGNN}\label{app:feedback-transfer}
The feedback experiment uses the same 20,000 training rows and two EGNN initializations. A first pass predicts provisional coordinates; their detached pair distances enter an invariant edge channel in the supervised second pass. Training uses 15,000 updates at batch size 32, matching the one-pass models' 960,000 example-forwards. The network contains 2,381,566 parameters, including 1,001 fixed schedule entries. Update counts and runtime differ.

We compare distance feedback with edge-inclusion probabilities from a regularized auxiliary tree distribution. Pooled graph validity on 32 internal-validation compositions selects one feedback type for both seeds. GAGA independently selects its maximum timestep from 350, 500, and 650. Validation chooses distances and timestep 650. We then generate 32 draws per seed for each of 32 previously ungenerated compositions, eight per size range, using 128 network calls and no physical refinement.

Distance feedback exceeds GAGA by 1.86 points (composition 95\% interval $[-0.34,4.44]$), with seed-specific differences $+0.39$ and $+3.32$. Tree feedback is 5.96 points worse than distance feedback ($[-8.11,-3.96]$), and is excluded from the method.

\paragraph{Fixed-recipe physical adaptation.}
Each selected parent generates 512 candidate anchors on eight training compositions. The same force-target procedure trains physical and replay students: 1,000 two-pass updates for FM or 2,000 one-pass updates for GAGA, at learning rate $10^{-4}$. We apply parameter subtraction with coefficient one and evaluate the same 32-composition panel without calibrating this strength on validation.

The unchanged recipe reduces both graph validity and joint yield. FM loses 4.00 joint-yield points ($[-6.49,-2.00]$), and GAGA loses 3.96 ($[-6.25,-1.95]$); eSEN gives the same directions. GAGA retains its fixed noise schedule. These results motivate the separately trained correction head in Appendix~\ref{app:matched-connection}, which uses broader supervision from each parent's trajectory states.
