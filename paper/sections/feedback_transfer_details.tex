\subsection{Geometry feedback and physical transfer on the EGNN}\label{app:feedback-transfer}
We test geometry feedback on the independent EGNN using the same 20,000 training
rows and two initializations. The first pass predicts provisional coordinates;
the second uses their pairwise distances in an existing invariant edge channel.
The provisional geometry is detached, and both passes are supervised. Thus this
experiment uses 15,000 updates at batch size 32 and two forward passes per example,
matching the 960,000 training forward passes of the original one-pass models.
The total parameter count is 2,381,566, including 1,001 frozen noise-schedule
entries. Optimizer-update counts and wall time are not matched.

An alternative replaces distances with edge-inclusion probabilities from a
regularized auxiliary tree distribution. On 32 internal validation compositions,
we select distance or tree feedback by pooled graph validity, with one choice for
both seeds. GAGA separately selects its maximum sampling timestep from
350, 500, and 650. Validation selects distance feedback and timestep 650.
We then evaluate 32 previously ungenerated compositions, eight in each of the
four size ranges, with 32 draws per composition and seed. Each output uses
128 network calls, without physical refinement.

\midrule
Harmonic FM, one pass &107&113&10.74\\
Harmonic FM, distance feedback &155&165&15.63\\
Harmonic FM, tree feedback &114&84&9.67\\
GAGA, selected timestep 650 &151&131&13.77\\

\end{table}

Distance feedback exceeds GAGA by 1.86 points, with a composition-bootstrap
95\% interval of $[-0.34,4.44]$. The seed-specific differences are $+0.39$
and $+3.32$ points. Tree feedback reduces validity relative to distance feedback
by 5.96 points ($[-8.11,-3.96]$), so it is not part of the proposed method.

\paragraph{Transferring the fixed physical-update recipe.}
Each selected parent generates 512 candidate anchors on eight training
compositions. We apply the same local force-target procedure, then fit physical
and replay students. Each FM student uses 1,000 two-pass updates; each GAGA
student uses 2,000 one-pass updates. The learning rate is $10^{-4}$ and the
parameter-difference coefficient is one. This is a follow-up on the same
32-composition panel. It tests this fixed recipe, without selecting its strength
on validation.

\midrule

GAGA &13.77&5.86\\

\end{tabular}

The full-strength update lowers both graph validity and joint quality for both
families. The within-FM joint-yield change is $-4.00$ points
($[-6.49,-2.00]$); the within-GAGA change is $-3.96$ points
($[-6.25,-1.95]$). eSEN gives the same directions. These results show that the
successful primary-backbone recipe cannot be transferred unchanged to this EGNN.
GAGA's predefined noise schedule stays fixed in this comparison.
Appendix~\ref{app:matched-connection} evaluates a separately trained correction
head with broader supervision from each parent's own trajectory states.
