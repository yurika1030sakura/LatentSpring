\section{Combined source and correction transfer to diffusion}\label{app:joint-design-transfer}
\paragraph{Structured diffusion noise.}
For a sampled tree $T$, let $B_T$ map independent standard Gaussian edge vectors to centered coordinates using the scales in Equation~\ref{eq:edge-law}. The covariance is $C_T=B_TB_T^\top$, and the forward process is
\begin{equation}
 X_t=\alpha_t X_{\rm clean}+\sigma_t B_T\Xi,
 \qquad \Xi\in\RR^{(N-1)\times3},\quad \Xi_{ij}\sim\mathcal N(0,1).
 \label{eq:structured-diffusion}
\end{equation}
The tree remains fixed along each trajectory, and reverse noise uses the same covariance. The denoiser receives invariant pair variances from $C_T$ and predicts coordinate noise $B_T\Xi$, following non-isotropic Gaussian diffusion \citep{voleti2022nonisotropic}. After training the target backbone for this process, we attach the frozen FM physical head through the endpoint interface. Appendix~\ref{app:main-implementation} gives the covariance channel and GAGA initialization.

EDM and GAGA each use two baseline initialization seeds, the same 20,000 references and batch schedules, and 30,000 updates per fit. Sampling uses the final EMA, 128 backbone evaluations, physical strength four, and no hydrogen readout. Native baselines reuse their original outputs on the same 64 compositions. Each setting contains 2,048 attempts.
