\section{Implementation and analysis of the main experiments}\label{app:main-implementation}
\paragraph{Model and training.}
The shared EGNN has four message-passing layers, 256 hidden features, and 2,381,566 backbone parameters. All experiments use neutral singlets, so only atom identities vary in the learned conditioning. The main model uses the harmonic-mixture source with edge log-width 0.2 and distance self-conditioning. Initial training uses AdamW for 15,000 updates at learning rate $10^{-4}$ and batch size 32, with two supervised passes per example and EMA decay capped at 0.999. The complete model adds 4,000 recovery updates and 10,000 geometric-head updates (Appendix~\ref{app:geometric-recovery}). The 20,000 training structures contain 8--64 atoms; evaluation covers 17--40 atoms, within the implementation limit of 200 (Appendix~\ref{app:matched-generators}).

The 7,106-parameter physical head uses 16-dimensional atom embeddings and a width-64 pair network, bounded by $2p^2$\,\AA\ per atom per unit progress. For each fit, 256 native trajectories across 128 training compositions yield 512 late endpoints and require 1,024 mirror-paired eSEN queries. We train on 96 compositions and assess target-prediction error on the other 32. AdamW runs for 20,000 updates at learning rate $3\cdot10^{-4}$. Targets use $T_{\rm phys}=300$ K, local width at most 0.03\,\AA, and molecular displacement norm at most 0.1\,\AA. Strength four was fixed before the five-fit confirmation and additional-baseline evaluation.

\paragraph{Sampling and compute.}
The main sampler uses 32 midpoint steps, requiring 128 backbone, 64 geometric-head, and 64 physical-head calls per output. Figure~\ref{fig:main-generators} evaluates raw coordinates before hydrogen readout, terminal perturbation, or optimization. Initial backbone training matches example-forward counts across methods; LatentSpring adds recovery, head fitting, and force-label preparation. All methods use 128 backbone sampling calls, while total training, FLOPs, and runtime differ. The continuation control matches the extra backbone updates. Archived zero-strength replay tests execute unused head calls for verification; those calls are unnecessary for an unaugmented baseline.

\paragraph{Evaluation and repetitions.}
The 64-composition panel contains 20 compositions with 17--28 atoms and 44 with 29--40, all absent from the processed training and validation corpora. Each fit generates 1,024 outputs. Figure~\ref{fig:main-generators} includes five LatentSpring and GAGA fits and two archived Gaussian FM and EDM fits. The three additional FM/GAGA fits follow the fixed method; the first two informed development (Appendix~\ref{app:seed-replication}). The later Gaussian FM and EDM evaluation reuses the panel with settings fixed before generation. Evaluation energies are not used to select checkpoints or outputs.

\paragraph{Component comparison.}
Figure~\ref{fig:source-head-ablation} uses the two archived one-pass Gaussian and harmonic FM parents from Appendix~\ref{app:matched-generators}, without self-conditioning or recovery continuation. Within each fit, both receive the same frozen self-conditioned-FM correction weights at geometric strength one and physical strength four. Corrected sampling uses 128 calls to the backbone and to each head. Source draws and sampler randomness are paired with the uncorrected outputs.

\paragraph{Structured diffusion.}
In Equation~\ref{eq:structured-diffusion}, $B_T$ is the centered tree embedding scaled by edge standard deviations, and $C_T$ has rank $N-1$. Let $D_T$ take oriented edge differences divided by those standard deviations. The loss $\|D_T(\widehat n-B_T\Xi)\|_F^2/[3(N-1)]$ is the inverse-covariance-weighted noise error on the centered subspace. The second invariant edge channel receives $\log[1+3(C_{T,ii}+C_{T,jj}-2C_{T,ij})]$, adding covariance information without learned parameters or observed bonds.

EDM initializes from $B_T\Xi$. GAGA initializes from a Gaussian with covariance $\alpha_t^2vP+\sigma_t^2C_T$ conditional on $T$, where $v$ is its original training-only coordinate variance and $P=I-\boldsymbol1\boldsymbol1^\top/N$. Both structured backbones use the baseline initializations, 20,000 references, batch schedules, and 30,000 one-pass updates. The FM physical heads remain fixed. This experiment retrains the diffusion backbones for the new source; Appendix~\ref{app:joint-design-transfer} reports the results.

\paragraph{Physical-head-only evaluation and checks.}
The earlier experiment transfers the same FM physical head to Gaussian FM, harmonic FM, and EDM in both archived fits, adding 12,288 raw outputs and GFN2 attempts without further training or eSEN queries. Released coordinate hashes, independently parsed physical logs, score arrays, and summaries record these results. A 48-output replay verifies that zero-strength correction reproduces native sampling. Table and contrast scripts read the released summaries and per-output arrays directly.
