\section{Implementation and analysis of the main experiments}\label{app:main-implementation}
\paragraph{LatentSpring configuration.}
The main model uses the shared EGNN with four message-passing layers, 256 hidden
features, and 2,381,566 backbone parameters. All experiments fix charge zero and spin multiplicity one; the learned
conditioning varies only with atom identities. The model uses the harmonic-mixture source and distance self-conditioning.
Training uses AdamW, a learning rate of $10^{-4}$, batch size 32, and 15,000
updates with two supervised forward passes per example. The initial exponential
moving average uses maximum decay 0.999. The final model then receives the
4,000-update recovery continuation and 10,000-update geometric-field training
in Appendix~\ref{app:geometric-recovery}. The source edge log-width
is 0.2. The implementation supports up to 200 atoms; the main evaluation
contains 17--40 atoms. The shared training set contains 20,000 OMol25 structures
with 8--64 atoms, as specified in Appendix~\ref{app:matched-generators}.

The physical head contains 7,106 parameters, a 16-dimensional atom embedding,
and a pair network with hidden width 64. Its velocity bound is $2p^2$\,\AA\
per unit progress. For each fit, 256 native trajectories on 128 training
compositions provide 512 late provisional endpoints. Mirror-paired eSEN
evaluations use 1,024 force queries. Of the 128 compositions, 96 fit the head
and 32 measure target-prediction error. Head training uses AdamW at learning
rate $3\cdot10^{-4}$ for 20,000 updates. Force targets use $T_{\rm phys}=300$ K,
a maximum local width of 0.03\,\AA, and a maximum molecular displacement norm
of 0.1\,\AA. The correction strength is fixed at four before the five-fit
confirmation and the additional-baseline experiment.

Generation uses 32 midpoint steps with two self-conditioning passes per field
evaluation: 128 backbone calls, 64 geometric-head calls and 64 physical-head calls per output. No terminal
coordinate perturbation, hydrogen readout, physical query, or geometry
optimization is used in Figure~\ref{fig:main-generators}. The initial backbone fits match training-example forward counts. LatentSpring
adds recovery continuation, geometric-head fitting, physical-head fitting and
teacher queries. All methods use 128 backbone sampling calls; total training,
FLOPs and wall time are not equated. The matched continuation experiment
measures the effect of the additional backbone updates.
Archived zero-strength controls execute unused head calls to verify sampler
behavior; those diagnostic calls are not part of an unaugmented baseline's
required inference procedure.

\paragraph{Evaluation and repetition counts.}
The 64-composition panel contains 20 compositions with 17--28 atoms and 44
with 29--40 atoms, all absent from the processed training and validation
corpora. Figure~\ref{fig:main-generators} uses five fits for LatentSpring and
GAGA, and two archived fits for Gaussian FM and EDM. Each fit produces 1,024
outputs. The extra three FM/GAGA fits were trained after freezing the method;
Appendix~\ref{app:seed-replication} separates these from the earlier two fits
that informed development. The Gaussian FM and EDM evaluations reuse the
same panel in a later experiment with settings fixed before generating their
outputs. No checkpoint or output is selected by its evaluation energy.

\paragraph{Four-setting component analysis.}
Figure~\ref{fig:source-head-ablation} uses the two archived, one-pass Gaussian
and harmonic FM parents from Appendix~\ref{app:matched-generators}. Both omit
self-conditioning, unlike the main LatentSpring row. Within each fit, we apply
the identical geometric and physical heads learned with the self-conditioned
FM, with strengths one and four and no target-specific training. Each corrected
output uses 128 backbone, 128 geometric-head and 128 physical-head calls.
The parent and corrected trajectories share source draws and sampler randomness.
The archived one-pass parents are used without recovery continuation; this
four-setting study measures source and correction effects on those fixed parents.

\paragraph{Structured diffusion in the combined-design transfer.}
In Equation~\ref{eq:structured-diffusion}, $B_T$ is the centered tree embedding
multiplied by the edge standard deviations, so $C_T$ has rank $N-1$. If $D_T$
takes oriented edge differences divided by their standard deviations, the
training loss is $\|D_T(\widehat n-B_T\Xi)\|_F^2/[3(N-1)]$, where $\widehat n$
is the denoiser's predicted coordinate noise. This is the inverse-covariance
weighted reconstruction error on the centered subspace. The existing second
invariant edge channel receives $\log[1+3(C_{T,ii}+C_{T,jj}-2C_{T,ij})]$.
The covariance adds no learned parameters and contains no observed chemical bonds.

EDM starts from $B_T\Xi$. At GAGA's selected truncation, the starting Gaussian
conditional on $T$ has covariance $\alpha_t^2vP+\sigma_t^2C_T$. Here $v$ is the
original training-only coordinate variance and $P=I-\boldsymbol1\boldsymbol1^\top/N$
removes translation. Thus GAGA retains its data-variance approximation while
using harmonic corruption noise. Both structured backbones use the paired
original random initializations, the original 20,000 references and batch
schedules, and 30,000 one-pass updates. The two FM physical heads remain frozen.
The target models are retrained, so this experiment transfers the two designs;
only the physical head is reused without retraining. Appendix~\ref{app:joint-design-transfer}
reports the completed generation and physical-score results.

\paragraph{Released evidence.}
The earlier physical-head-only experiment evaluates all three target baselines (Gaussian FM,
harmonic FM, and EDM), with and without the same transferred FM head, in both
archived fits. It adds 12,288 generated outputs and fixed-coordinate GFN2
attempts, with no new training or eSEN queries. Raw-coordinate hashes,
independently parsed physical logs, all-output score arrays, and numerical
summaries are archived in the released evidence. A separate 48-output replay
check verifies that zero-strength correction reproduces native sampling.
The main-table renderer reads the audited summaries directly; the four-setting
analysis script reconstructs its contrasts from the released score arrays.
