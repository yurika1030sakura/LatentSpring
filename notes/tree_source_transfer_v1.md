# Broader source-framework comparison after the context ablation

The true/sham/no-context experiment is complete and audited. The actual context
head does not establish useful generation gains and should not be scaled or
retuned against those outputs. This next study tests the already supported
source-framework effect on a broader, prospectively selected condition panel.
It does not treat a failed neural adapter as a successful method.

The32-composition panel was frozen before the context comparison finished. It
selects four metadata-hash ranks in each of eight size/charge/spin strata from
official development candidates and excludes the three declared earlier panels.
No element, energy or generated-output filter was used. It is additional
development evidence, not a certified composition-disjoint pretraining test set.
The722 reserved outcomes remain unqueried.

Freeze the same two continuation checkpoints for each of ordinary Gaussian,
fixed shell tree and harmonic tree; their identity is set before any output on
this panel. Use32 draws per condition:6,144 new outputs in total, with no new
training and zero new oracle queries. Keep all outcomes, including unsupported
elements and radical/metal graph-perception failures. Do not select different
source methods separately for each seed.

Primary comparisons are shell minus Gaussian, harmonic minus Gaussian, and shell
minus harmonic. Report both seeds separately, per-condition values, graph/geometry
support, fragmentation, exceptions, diversity and inference cost. Provide paired
within-composition intervals conditional on this panel, and a descriptive bootstrap
over compositions within the prespecified strata to expose between-condition
heterogeneity. The latter is not a confidence certificate for arbitrary unseen
OMol25 compositions or for the whole pretraining distribution.

This experiment asks whether the source architecture has useful effects beyond
the heavily reused eight-condition panel. It introduces no new network or physics
identity. Broader evidence can support the source method even if the optional
affinity/context modules do not help, but a positive result still does not establish
ICLR originality, competitive completeness or a Boltzmann-distributed generator.
