# Completed context and broader-source studies: evidence and next decision

All work in these two studies is complete and audited. The static context adapter
has no demonstrated useful increment. Source geometry improvements extend to the
additional32-composition panel, but graph-acceptance superiority is not established
for the fixed shell source on that panel. Reference assay coverage is poor, so
graph acceptance cannot be interpreted as universal chemical validity on this domain.
The ICLR goal remains active and scientifically unachieved.

## Actual source-tree context did not help

Both actual/sham adapters have identical initialization, parameter counts and
learning rates; all methods share source coordinates and training rows within each
continuation. All3,072 sources, source/context trees and structural outcomes replay.
Full checkpoints restore and the adapter receives nonzero gradients and updates.

## Original-reference assay calibration

After freezing and completing generation,32 original reference geometries were
recovered by raw-record/source/composition/charge/spin identity; stored original
energy labels also matched. No reference was supplied to generation or fitting.
The unchanged assay passes only6/32 reference graphs and20/32 geometries. Twelve
references are disconnected, none overlaps, and12 trigger validator errors.
There are16 conditions with zero graph passes across all six generated arms;
none of their reference graphs passes the assay, although11 pass geometry.

These facts expose target-domain and assay-coverage limitations. A raw reference
may be reactive, distorted or multicomponent, so rejection does not itself prove
a validator bug. Neither a latent dependence tree nor RDKit graph perception
certifies electronic state or physical stability. The frozen primary results and
denominators remain unchanged; reference-qualified subsets cannot retroactively
replace them or rescue the context adapter's negative result.

## Immediate next work

Define and freeze a coherent primary single-molecule evaluation domain before
another architecture sweep. A possible primary domain is connected organic
monomers with electronic conditions supported by the chosen graph assay, selected
using original references and metadata before any new generated outcomes. Keep
the current broader molecular-system panel as a separate stress test with explicit
geometry/energy/assay coverage. State the scope reduction openly; it is not a
whole-OMol25 or perfect-generator claim. Preserve all old outcomes.

Audit the reference criterion and available eligible pool first; do not choose
conditions by which method wins. Any new evaluation panel must exclude declared
previous evaluation/training panels and clarify pretraining overlap. No replacement
panel, new attention operator or new successful architecture is claimed here.
Once the task/readout is coherent, test the simplest frozen source methods and
only then a mechanism-based learned improvement on that same task.

The learner has to improve chemically meaningful outputs, not just source NLL,
FM training loss or connectivity. More network complexity is not a substitute
for that evidence. Source learning and latent conditioning have direct prior art;
neither a new physics law nor every element working is required for the paper,
but the actual contribution still needs defensible originality and utility.
